## What I build

**Data pipelines and infrastructure.** Most of my recent work is a series of from-scratch implementations of tools I use daily. No frameworks, no dependencies, just the core algorithms:

| Project | What it is |
|---------|-----------|
| [**streamlite**](https://github.com/hajirufai/streamlite) | Stream processing engine - windowing, watermarks, keyed state, checkpoints. Flink internals demystified. |
| [**brokerlite**](https://github.com/hajirufai/brokerlite) | Message broker with pub/sub, consumer groups, WAL, dead letter queues. Kafka-inspired. |
| [**raftkv**](https://github.com/hajirufai/raftkv) | Distributed key-value store with Raft consensus - leader election, log replication, strong consistency. |
| [**queryforge**](https://github.com/hajirufai/queryforge) | SQL query engine - lexer, parser, optimizer, executor. SELECT, JOIN, GROUP BY, subqueries over CSV/JSON. |
| [**searchlite**](https://github.com/hajirufai/searchlite) | Full-text search engine - inverted index, BM25 scoring, Porter stemmer, faceted search. |
| [**cachelite**](https://github.com/hajirufai/cachelite) | In-memory cache with LRU/LFU/FIFO eviction, TTL, snapshots, HTTP API. |
| [**cronlite**](https://github.com/hajirufai/cronlite) | Task scheduler - POSIX cron syntax, priority queues, DAG dependencies, retry strategies, SQLite persistence. |
| [**vaultlite**](https://github.com/hajirufai/vaultlite) | Secrets manager with AES-128 from scratch. Envelope encryption, seal/unseal, audit logging, versioning. |
| [**gatelite**](https://github.com/hajirufai/gatelite) | API gateway - routing, rate limiting, JWT auth, circuit breaking, load balancing, caching. |
| [**tracelite**](https://github.com/hajirufai/tracelite) | Distributed tracing - W3C Trace Context, sampling, critical path analysis, waterfall visualization. |
| [**servekit**](https://github.com/hajirufai/servekit) | HTTP/1.1 server built from raw TCP sockets. |
| [**tinylang**](https://github.com/hajirufai/tinylang) | Programming language interpreter - lexer, parser, AST, closures, first-class functions. |

Every one of these is zero dependencies, pure Python standard library.
